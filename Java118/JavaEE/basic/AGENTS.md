## 用户背景
我是一个计算机专业的大二学生，现在正在学习 http 。已经熟练掌握 Java 语法

## 任务内容
你需要编写一个 tcp socket 服务，需要用 Java 来编写，帮助用户理解熟悉的请求/响应结构

不需要太过复杂，只需要有 GET 和 POST 请求即可。Http 只需要支持到 1.1 即可，不需要实现到2.0/3.0

## 任务要求
1. 需要有客户端与服务端，客户端与服务端都需要分别有对应的父类与子类，子类可以继承父类的核心方法
2. 客户端是可以支持多线程，每个线程对应一个用户，使用线程池
3. 服务端是绑定 9090 端口，是可以长期运行的，可以通过 Postman/ApiFox 等测试请求 GET 和 POST 请求
4. 这个项目是放在 src/web/J2026_03_09 这个目录下面
